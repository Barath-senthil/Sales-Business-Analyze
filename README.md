# 📊 Excel Business Analytics Dashboard

An interactive Excel Dashboard project developed using **Microsoft Excel, Power Query, Pivot Tables, Pivot Charts, and Slicers** to analyze customer behavior, revenue trends, profit distribution, and overall business performance.

---

# 🛠️ Tools & Technologies Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization

---

# 📌 Project Overview

This project transforms raw business data into interactive dashboards that provide meaningful insights for decision-making.

The dashboard includes:

- Customer Insight & Engagement Analysis
- Revenue & Profit Analysis
- Business Health Monitoring
- Regional Sales Performance
- Product Performance Tracking
- Seasonal Trend Analysis

---

# 📊 Dashboard Features

## 1️⃣ Customer Insight & Engagement Dashboard

### Key Metrics
- Total Customers
- Repeat Purchase Count
- Average Customer Value
- Loyalty Score

### Insights
- Customer performance by city
- Payment method analysis
- Customer segment distribution
- Orders & profit by gender
- Order status distribution

---

## 2️⃣ Category Wise Revenue & Profit Dashboard

### Key Metrics
- Total Cost
- Total Profit
- Profit Margin
- Shipping Cost

### Insights
- Sub-category revenue distribution
- Top-performing products
- Revenue vs Profit comparison
- Seasonal order trends
- Customer income-level analysis

---

## 3️⃣ Business Health Overview Dashboard

### Key Metrics
- Total Customers
- Total Orders
- Total Quantity
- Total Revenue
- Total Profit

### Insights
- Revenue contribution by category
- Regional sales performance
- Revenue trends over time
- Regional revenue comparison
- Seasonal business analysis

---

# 📈 Key Business Insights

- Electronics category generated the highest revenue.
- Middle East region contributed strong sales performance.
- Summer season recorded higher order activity.
- Debit Card and PayPal showed better payment success rates.
- Loyal customers contributed significantly to repeat purchases.
